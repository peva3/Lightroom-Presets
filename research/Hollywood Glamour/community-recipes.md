# Community Lightroom Recipes — Hollywood Glamour

Notes for adapting the **Hollywood Glamour** preset. This is a *high-key, toned studio print* look: 1930s–40s 8×10 glamour portraiture, retouched and usually sepia-toned.

## Reference Looks

- **George Hurrell, Joan Crawford (1932), Jean Harlow (1935), Marlene Dietrich** — hard key above and in front, sculpted shadow, glowing skin, pencil-retouched highlights.
- **MGM publicity still, sepia-toned gelatin silver** — warm brown-black, no neutral grey, paper-white held in the gown rather than the face.
- **Paramount / butterfly lighting** — nose shadow as a design element, not a flaw.
- **Contemporary re-creations** — one hard source, dark background, white or chiffon wardrobe.

## Slider Starting Points

| Panel | Range | Contributes |
|---|---|---|
| Exposure | +0.20 to +0.50 | High-key print density |
| Contrast | -10 to 0 | Negative contrast: the lighting already supplies the drama |
| Highlights | -30 to -45 | White gown, cheek specular |
| Shadows | +15 to +30 | Open, creamy shadow side |
| Whites | +5 to +15 | Paper white without clipping |
| Blacks | 0 to +12 | Lifted black point = toned print |
| Clarity | -5 to -15 | Diffusion bloom / uncoated-lens glow |
| HSL Orange lum | +8 to +16 | Creamy skin |
| HSL Orange sat | -8 to 0 | Removes ruddiness (the panchromatic "creamy rather than burnished" reading) |
| HSL Blue / Green sat | -5 to -15 | Suppresses ambient colour so the frame reads as toned monochrome |
| HSL Yellow sat | 0 to +8 | Mid-tone warmth |
| Color Grade highlight | 35–45 hue / 5–10 sat | Warm highlight roll-off |
| Color Grade shadow | 25–35 hue / 3–8 sat | Sepia in the shadow, never blue |
| Grain | 0 | Retouched 8×10 contact print |
| Vignette | -8 to -15 | Studio falloff |

## Common Mistakes

- **Adding contrast.** The most common error. A hard-lit face plus Contrast +20 is a look no 1930s print has; the preset is already compensating for the lighting.
- **Adding grain for "vintage".** These negatives were retouched smooth; grain is the opposite of the style.
- **Pushing Clarity positive.** Positive clarity hardens skin texture and destroys the diffusion that defines the look.
- **Saturating orange.** Ruddy, saturated skin reads as modern beauty retouching, not glamour.
- **Cooling the shadows.** A blue shadow grade turns sepia into a modern teal-orange portrait.
- **Treating it as a B&W preset.** It is a *toned colour* image; for true monochrome use the Black & White category instead of desaturating this one.
